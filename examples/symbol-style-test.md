# 符号分点样式测试

验证分点前缀符号可以直观指定不同样式。

## [] 大方块分点

[] **需求真实**：用了上千次，哪里不爽你身体记得
[] **大厂顾不上**：它们只做几亿人的最大公约数
[] **AI 给了机会**：一个人就能做只服务自己的定制版

## · 小方点卡片

· **保存 Markdown**：保留编辑内容
· **下载 HTML**：导出可独立打开的页面
· **实时预览**：右侧同步展示当前页面

## :: 标题加多分点

:: **痒点**：想想就过，不解决也无所谓；你不会真去用
:: **痛点**：反复扎你，不解决持续难受；你愿意为它付出代价
:: **爽点**：能明显提升体验；但不影响核心流程

## 数字序列型

2. **进阶使用**：写脚本、做小工具、处理文件和数据
3. **复杂项目**：做产品规划和大型项目编码
